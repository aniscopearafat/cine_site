# CineVault PHP/MySQL

Upload-ready CineVault for standard Apache/PHP/MySQL hosting. See `INSTALLATION.md` before uploading.

Features include movies, series, separate season and episode management, external watch links, multiple download links, download click analytics, moderators, reports, TMDb/OMDb/TVMaze metadata import, Adsterra-friendly ad placements, customizable branding and footer social links, mobile layouts, and an embedded YouTube trailer player.

No Node.js, build process, or command line is required on the hosting account.
